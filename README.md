# 随笔

一个只用来写字的安卓 App。手机上写，回到电脑上双击一下，笔记就变成 md 文件落到本地。

- 版本：1.0.4
- 平台：Android 7.0+（minSdk 24）
- 体积：约 60 MB（含内置字体）
- 无网络权限以外的权限；不联网，只连局域网内的同步程序

## 功能

- 打开就写，写一个字存一次，没有保存按钮
- 宋体排版（思源宋体 GB2312 子集），纸 / 夜两套配色
- 设置里可调字号（14–28）、纸色、墨色，纸色和墨色支持自定义取色
- Markdown 语法与快捷条：`#` `##` 粗体 斜体 列表 引用 分隔线 代码，可切换预览
- 列表页长按进入多选，可批量删除
- 每篇显示最后编辑时间：今天显示时分，隔了几天补上日期
- 单向同步到电脑：手机 → 电脑，电脑端存成 `.md`

## 使用

### 手机

1. 安装 `suibi-1.0.4.apk`
2. 写。主界面右上角三个图标：太阳/月亮（换纸色与夜色）、云朵（同步）、滑杆（设置）

### 电脑（同步接收器）

需要 Python 3，只用标准库，不用装任何依赖。

1. 把 `pc/` 整个目录拷到电脑上（任意位置）
2. 双击 `随笔同步.cmd`，窗口里会显示**地址**和**口令**
3. 手机 App 里点云朵，填地址和口令，点「立即同步」
4. 笔记以 `.md` 文件形式出现在输出目录

输出目录默认是**用户目录下的 `随笔` 文件夹**（Windows 上是「C 盘 → 用户 → 你的用户名 → 随笔」）。想换地方，在 `pc/` 里新建一个 `config.txt`，第一行写目标路径就行；也可以在启动时加 `--dir "路径"`。

说明：

- 手机和电脑要在**同一个局域网**。很多学校、公司 WiFi 会隔离设备，这种时候用手机的「USB 网络共享」给电脑联网即可
- 窗口要一直开着；空闲 15 分钟自动退出
- 同步是单向的（手机 → 电脑），电脑上改文件不会回传；手机上删掉的，电脑上不删
- 口令保存在 `pc/token.txt`，改完重启同步程序生效
- 端口默认 8730，被占用时自动往后试

### 从源码构建

需要 Flutter 3.47+ 和 Android SDK：

```
flutter pub get
flutter build apk --release
```

## 目录

- `lib/`：应用代码
- `assets/fonts/`：思源宋体子集（三种字重）
- `pc/`：电脑端同步接收器（Python 标准库单文件）
- `android/`：安卓工程

## 说明

- 数据全部存在手机本地（`notes.json`），不经过任何服务器，卸载即删除
- Markdown 预览使用 `flutter_markdown`
- 字体由 Noto Serif CJK 子集化而来，遵循 SIL Open Font License 1.1
